# ربات پاسخ‌گوی فارسی تلگرام

این پروژه یک ربات تلگرام می‌سازد که در **چت خصوصیِ خودِ ربات** به پیام‌ها با فارسی طبیعی و صمیمی پاسخ می‌دهد.

## نکته مهم درباره تلگرام
ربات رسمی تلگرام نمی‌تواند پیام‌هایی را که افراد به حساب شخصی تلگرام شما می‌فرستند بخواند یا از طرف حساب شخصی شما جواب بدهد. افراد باید وارد صفحه ربات شوند و دکمه Start را بزنند. این پروژه برای همین گفت‌وگوی خصوصی با حساب ربات است، نه گروه‌ها و نه حساب شخصی شما.

## راه‌اندازی

1. در تلگرام به `@BotFather` پیام بدهید.
2. دستور `/newbot` را بفرستید و نام و شناسه ربات را تعیین کنید.
3. توکن ربات را دریافت کنید. توکن را برای هیچ‌کس نفرستید.
4. از پنل API شرکت OpenAI یک کلید API بسازید. استفاده از API ممکن است هزینه جداگانه داشته باشد.
5. Python نسخه 3.10 یا بالاتر را روی رایانه یا سرور نصب کنید.
6. از فایل `.env.example` یک کپی با نام `.env` بسازید و توکن و کلید API را داخل آن قرار دهید.
7. در ترمینال، داخل پوشه پروژه این دستورات را اجرا کنید:

```bash
python -m venv .venv
# ویندوز:
.venv\Scripts\activate
# لینوکس یا مک:
source .venv/bin/activate

pip install -r requirements.txt
python main.py
```

تا وقتی برنامه روی رایانه یا سرور روشن باشد، ربات پاسخ می‌دهد. برای فعالیت ۲۴ ساعته باید آن را روی یک سرور همیشه‌روشن اجرا کنید.

## فرمان‌ها

- `/start` فعال‌سازی پاسخ‌گویی در همان گفت‌وگو
- `/stop` توقف پاسخ‌گویی در همان گفت‌وگو
- `/pause` توقف سراسری (فقط اگر `OWNER_CHAT_ID` تنظیم شده باشد)
- `/resume` فعال‌سازی مجدد سراسری (فقط اگر `OWNER_CHAT_ID` تنظیم شده باشد)

برای فعال‌کردن کنترل سراسری، ابتدا شناسه عددی چت خودتان را به دست آورید و در `OWNER_CHAT_ID` قرار دهید.

## شخصی‌سازی لحن
متن `SYSTEM_PROMPT` در فایل `main.py` رفتار و لحن ربات را تعیین می‌کند. برای نزدیک‌ترشدن به سبک نوشتاری شما، چند نمونه پیامِ خودتان را به‌صورت غیرمحرمانه بررسی و متن دستورالعمل را بر همان اساس اصلاح کنید.

## حریم خصوصی و محدودیت‌ها
- تاریخچه کوتاه گفتگو فقط در حافظه موقت برنامه نگهداری می‌شود و با راه‌اندازی مجدد پاک می‌شود.
- متن پیام‌ها برای تولید پاسخ به سرویس API هوش مصنوعی ارسال می‌شود.
- اطلاعات حساس، رمزها، کدهای ورود و اطلاعات بانکی را در گفتگوها ارسال نکنید.
- ربات نباید بدون بررسی شما قول یا تعهد مهمی بدهد.
